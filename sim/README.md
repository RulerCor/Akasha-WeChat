# sim/ — 微信对话模拟器（附属测试工具）

一个独立的 OneBot v11 客户端，直连 AstrBot 测试机器人的回复效果。
消息走与真微信**完全相同的管道**（唤醒判定 → 人设 → 知识库 → 回复），
区别仅在于回复显示在本地网页里，**不会发到真微信**。

## 能用来做什么

- 测试人设与防穿帮规则（知识库、模型名、称呼……说漏了立刻能看到）
- 验证群聊语境注入、随机插话概率
- 不打扰真实群友地调试回复风格

## 启动

```bat
cd sim
python sim_wechat.py
```

然后打开 <http://127.0.0.1:8767>。依赖只有 `pip install websockets`。

Windows 下也可以直接双击 `start_sim.bat`（优先使用桥接项目自带的 venv）。

## 测试身份

左侧可选四个身份；**与真实会话相同 ID 的身份会共用同一套人设、知识库与对话记忆**
（这就是为什么测试结果能代表真实表现）。换成自己的环境时，编辑
`sim_wechat.py` 顶部的 `PROFILES`：私聊填 `user_id`，群聊填 `group_id`，
ID 可以用 `/sid` 指令查询。

## 自动化测试

```bat
python sim_wechat.py autotest
```

跑 10 个固定场景（功能询问 / 模型名 / 知识库穿帮 / Markdown 格式 / 群聊唤醒与随机插话），
自动检查回复中是否出现「知识库」类禁词与 Markdown 记号，生成
`sim/模拟对话测试报告.md`。

## 注意

- 模拟器的 self_id 与真桥接不同，二者可以同时连接 AstrBot，互不干扰。
- 模拟器直发的事件**绕过了真桥接的门槛**（裸指令拦截、群图片 @ 等待窗、消息缓冲），
  所以「真微信里会被桥接拦掉的消息」在这里能得到 AstrBot 的原生反应。
- 测试消息会进入对应真实会话的对话记忆，介意的话在对应会话发 `/reset`。
