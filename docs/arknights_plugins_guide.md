# 三个明日方舟插件使用指南

安装日期：2026-09-20 ｜ 全部已启用并通过加载自检 ｜ 依赖已满足

> 三个插件**互不冲突**：罗德岛终端用 `ark` 前缀，终末地用 `zmd`/中文指令，
> 甘特图用 `/方舟日程`。已实测同时加载无冲突。
>
> ⚠️ 与旧插件 `skland_remind`（森空岛签到）功能重叠，**建议保持禁用**——
> 罗德岛终端已完全覆盖其签到/理智提醒能力，两者同时开会重复推送。

## 1. 罗德岛终端（astrbot_plugin_arknights v0.3.6）

**用途**：明日方舟数据查询 + 抽卡分析 + 签到 + 官方公告推送。全部指令以 `ark` 开头。

### 首次使用：扫码绑定
```
/ark绑定          ← 生成森空岛扫码图，用森空岛 APP 扫
/ark绑定列表      ← 查看已绑定的角色
/ark切换绑定      ← 多角色时切换
/ark删除绑定
```
最多绑定 5 个角色（`max_bindings`）。

### 日常高频
| 指令 | 作用 |
|---|---|
| `/ark理智` | 当前理智值 |
| `/ark签到` | 手动签到 |
| `/ark便签` | 游戏内便签 |
| `/ark任务` | 任务进度 |
| `/ark基建` | 基建设施 |
| `/ark剿灭` | 剿灭作战进度 |
| `/ark肉鸽` | 集成战略进度 |

### 查询类
| 指令 | 作用 |
|---|---|
| `/ark干员 名称` | 干员详情（立绘/职业/稀有度/精英化/潜能） |
| `/ark干员列表` | 干员一览 |
| `/ark公招` | 公开招募标签计算 |
| `/ark公告` / `/ark公告最新` | 官方公告（保留富文本与配图） |
| `/ark面板` | 综合数据面板 |

### 抽卡分析（本插件最强功能）
```
/ark抽卡分析同步   ← 从官网导入抽卡记录（本地持久化，按
                     (卡池类别,时间,位置) 去重合并，历史只增不减）
/ark抽卡分析       ← 查看统计：平均出六 / 平均UP / 总抽数 / 当前保底
                     + 六星序列 + UP/歪判定 + 欧非评级
/ark抽卡记录       ← 原始记录
/ark抽卡重置
```

### 订阅（推送到发起指令的那个会话）
```
/ark订阅理智       ← 理智回满推送
/ark订阅公告       ← 新公告推送
/ark订阅签到       ← 签到结果通知
/ark取消订阅理智 / /ark取消订阅公告 / /ark取消订阅签到
```

### 关键配置（WebUI → 插件 → 罗德岛终端）
| 项 | 当前值 | 说明 |
|---|---|---|
| `sign_time` | `00:05` | 每日自动签到时刻 |
| `sanity_poll_interval` | 20 | 理智轮询间隔（分钟） |
| `announce_poll_interval` | 30 | 公告轮询间隔（分钟） |
| `max_bindings` | 5 | 最多绑定角色数 |
| `secretary_art` | 精一立绘 | 看板立绘规格 |
| `announce_push_cards` | 3 | 公告推送附图数 |

## 2. 终末地协议终端（astrbot_plugin_endfield v3.0.2）

**用途**：《明日方舟：终末地》数据查询 + 签到 + 订阅。
支持中文指令与 `zmd` 前缀两种写法。

### 首次使用：绑定（三选一）
```
/扫码绑定        ← 森空岛扫码（推荐）
/手机绑定
/授权登陆
/国际服登录      ← 国际服玩家用这个
```

### 查询类
| 指令 | 作用 |
|---|---|
| `/理智` | 当前理智 |
| `/便签` | 游戏内便签 |
| `/日历` | 活动日历 |
| `/公告` / `/公告最新` | 官方公告 |
| `/干员列表` | 干员一览 |
| `/同步面板` | 同步数据面板 |
| `/全服统计` | 全服数据 |
| `/危机合约` | 危机合约进度 |
| `/地区建设` / `/帝江号建设` | 建设进度 |
| `/成就列表` | 成就 |
| `/抽卡分析` / `/抽卡记录` / `/抽卡分析同步` | 抽卡统计 |

### 绑定管理
`/绑定列表` `/切换绑定` `/删除绑定`

### 订阅
`/订阅理智` `/订阅公告` `/订阅调度券` 及对应 `/取消订阅*`

### 关键配置
| 项 | 当前值 | 说明 |
|---|---|---|
| `auto_sign_in` | `true` | 自动签到已开 |
| `auto_sign_in_time` | `00:05` | 签到时刻 |
| `auto_sign_in_notify_group` | `""`（空） | **签到结果通知群——留空则不发** |
| `sanity_poll_interval` | 20 | 理智轮询间隔 |
| `announcement_poll_interval` | 10 | 公告轮询间隔 |
| `api_key` | `""`（空） | 可选，留空走扫码绑定 |

## 3. 明日方舟甘特图（astrbot_plugin_ganttknights v0.1.2）

**用途**：一张长图看清近期活动排期（活动/卡池时间轴、凭证兑换、新增时装、新增模组）。
数据来自 PRTS Wiki。

### 指令
| 指令 | 作用 |
|---|---|
| `/方舟日程` | **出图**（首次会自动抓取数据，稍慢） |
| `/甘特图状态` | 数据新鲜度 / 日差 / 推送状态 |
| `/甘特图刷新` | 强制刷新数据 |
| `/甘特图初始化` | 首次初始化 |
| `/甘特图帮助` | 帮助 |

### 定时推送（当前**未开**）
配置里 `push.enabled = false`、`push.targets = []`。
要开每日推送需两步：
1. `push.enabled` 改为 `true`
2. `push.targets` 填入目标会话 UMO（如 `wechat_bridge:GroupMessage:125237337`）
   —— 在目标群发 `/sid` 可查到

推送特性：只在「即将结束 / 今天开启」这类节点附一句文字，平时只发图。

### 关键配置
| 项 | 当前值 | 说明 |
|---|---|---|
| `render.left_offset_days` | 3 | 时间窗左边界（往前 3 天） |
| `render.right_offset_days` | 22 | 时间窗右边界（往后 22 天） |
| `panels.voucher/outfit/module` | 全 `true` | 底栏：凭证/时装/模组面板 |
| `data.auto_refresh_daily` | `true` | 每日自动刷新数据 |
| `notify.end_offsets` | `[-3,-1]` | 活动结束前 3 天、1 天提醒 |
| `notify.start_offsets` | `[0]` | 活动开启当天提醒 |

## 排查备忘

- **依赖**：matplotlib / numpy / Pillow / httpx / APScheduler / qrcode — 已全部装好
- **命令没反应**：微信群里指令需 **@机器人**（群为 mention 模式）；
  私聊直接发即可
- **扫码绑定时**：图会以图片形式发到当前会话，用森空岛 APP 扫
- **甘特图首次出图慢**：要现抓 PRTS 数据，之后走缓存
- **三个插件都不占用 `kb_names`**，与知识库系统无交互
