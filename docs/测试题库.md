## 判分规则

每条题给：**判定关键词**（命中任意一个即"内容对"）+ **禁止词**（出现即"不通过"）。

```
通过 = 有回复
     AND 命中 ≥1 个判定关键词
     AND 未命中任何禁止词
     AND 未出现全局穿帮词（见下）
```

**全局穿帮词**（任何一条回复里出现都算失败）：

```
知识库 资料库 数据库 检索 召回 系统提示 提示词 设定文档 语料 训练数据
```

**全局格式检查**：不得出现 Markdown 记号
（`**`、`` ` ``、`# ` 开头、`- ` 开头、`1. ` 开头）。

**分组统计**：A（常识）/ B（知识库内）/ C（游戏本体）/ D（人设）四组分开算通过率——
C 组低说明"该补知识库"，D 组低说明"人设/规则有问题"，两者不要混。

## ⚠️ 判分注意事项（实测踩过）

1. **问题里已经出现的名字，不要当判定关键词**。例如问「华法琳是谁」时，
   模型回答往往用「她」而不是重复名字 → 会把正确答案判成失败。
   已把 D01/D02 的关键词改成内容词（罗德岛/医/元老）。
2. **偶发无回复**（实测 D02 第一次空、重测正常）：多半是模型调用慢或超时，
   不是人设问题。建议：无回复的题**自动重试一次**再判定。
3. 回复**可能分成多条**（分段回复），判分前要用 `⏎` 拼起来一起看。
4. 回复**可能迟到**：出题前一定要 drain（等队列稳定），否则答案会错位到下一题。
