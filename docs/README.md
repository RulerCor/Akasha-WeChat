## 子目录

| 目录 | 放什么 | 收录规则 |
|---|---|---|
| `delivery/` | **交付说明**（一轮需求的背景/做法/验证） | 命名 `delivery-YYYYMMDD-主题.md`，发版时对应 CHANGELOG 条目 |
| `design/` | **设计文档**（子系统方案、插件指南、题库等长期参考） | 独立子系统/机制一份 |
| `history/` | **历史实录**（排障报告、考据、一次性调研结论） | 解决后不再更新；引用数据以当时为准 |
| `upstream/` | **上游文档**（alingalingling 原仓库的 SETUP / AI 速查） | 原样保留，不修改 |

## 归档规则（何时放哪）

1. **做完一轮需求** → `docs/delivery/delivery-YYYYMMDD-主题.md`（交付说明模板见既有文件）。
2. **新子系统上线** → `docs/design/` 下一份长期设计文档。
3. **排障/考据结束** → `docs/history/` 下一份实录（带日期）。
4. **上游原样文档** → 只进 `docs/upstream/`，永不混入自产文档。
5. 根目录只留「现在还要用」的文档；过期的移入子目录，**不删除**。
