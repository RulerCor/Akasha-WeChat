# Akasha 便携版 · 使用说明

解压即用，**不需要安装 Python、不需要安装 AstrBot、不需要 pip 装依赖**。
所有运行环境都已经打包在里面。

---

## 一、开始之前：有两样东西必须你自己准备

| 必须准备 | 为什么不能打包 |
|---|---|
| **微信桌面版**（装好并登录） | 机器人靠"操作微信窗口"来发消息，所以必须有微信；微信是腾讯的软件，不能随包分发 |
| **一个模型 API Key** | 属于个人凭据，打包进去就等于泄露；首次配置时填自己的即可 |

> 另外：**微信窗口启动后请保持打开**（最小化可以）。窗口完全关掉就发不出消息了。

---

## 二、三步跑起来

### 第 1 步：装微信 + 登录

装好微信桌面版，扫码登录。建议先随便点开一个聊天，确认微信能正常收发。

### 第 2 步：准备 WeFlow

包里自带 WeFlow（`app\weflow\WeFlow.exe`）。

1. 双击运行 `app\weflow\WeFlow.exe`
2. 按它的引导完成一次初始化（它会读本机微信的数据）
3. 到设置里确认 **HTTP API 已开启**（端口 `5031`）

> WeFlow 只负责**读**消息，不负责发。发送走另一条路（操作微信窗口）。

### 第 3 步：跑首次配置，然后启动

1. 双击 **`① 首次配置.bat`**
   - 它会自动从 WeFlow 配置里读 Access Token（读不到就手填）
   - 问你机器人在微信里的昵称
   - 让你选一家模型服务商并填 Key（DeepSeek / Kimi / 硅基流动 / 通义 / OpenRouter / 自定义）
2. 双击 **`启动 Akasha.bat`**
   - 自动校正运行环境路径
   - 依次拉起 WeFlow → AstrBot → 桥接
   - 最后自动打开控制面板 `http://127.0.0.1:8766`

想停止：双击 **`停止 Akasha.bat`**（一次全停）。

---

## 三、跑起来之后怎么看

| 面板 | 地址 | 用途 |
|---|---|---|
| 桥接面板 | http://127.0.0.1:8766 | 连接状态、实时日志、**基础设置 / 成员与权限** |
| AstrBot 面板 | http://127.0.0.1:6185 | 人设、知识库、定时任务、模型 |

**先在群里 @ 一下机器人**，看它回不回。

---

## 四、第一次用，建议在桥接面板里配这几项

打开 http://127.0.0.1:8766 →「成员与权限」：

- **群里管什么**：每个群一行两列
  - 「回复」开关 = 这个群要不要回复（立即生效）
  - 「插嘴」勾选 = 允许它自己冒出来说话（不勾 = 进黑名单，需保存）
- **成员表**：勾选谁是管理员

「基础设置」里可以改机器人昵称、消息缓冲秒数、群聊模式等。

## 五、常见问题

**Q：启动后一直没反应？**
先看两个日志：`app\astrbot\astrbot_run.log`、`app\bridge\bridge_run.log`。
AstrBot 首次启动慢（40~90 秒）属正常。

**Q：消息发不出去？**
1. 微信窗口是不是被完全关掉了？（必须开着）
2. WeFlow 在不在运行？面板上 WeFlow 是不是绿的？
3. 目标会话名对不对？

**Q：机器人不回话？**
多半是模型没配好 —— 重跑一次 `① 首次配置.bat`，或直接进 AstrBot 面板 6185 检查模型。

**Q：能换模型吗？**
能。进 AstrBot 面板 6185 → 模型服务商，加一个即可。**换模型后记得给它设**
`max_context_tokens`（建议 65536），否则上下文长度会用默认值。

**Q：换台电脑怎么办？**
整个文件夹拷过去，双击 `启动 Akasha.bat` 就行 —— 启动脚本会自动把环境路径改成新位置。
`① 首次配置.bat` 不用重跑（配置在里面了），但微信和 WeFlow 需要在新电脑上重新准备。

## 六、维护（进阶，可以不管）

`tools\` 里有维护脚本。**AstrBot 若被升级，必须重打补丁**：

```bat
python\python.exe tools\check_patches.py     :: 一条命令看哪些补丁掉了
```

按提示逐条重打即可（每个补丁脚本都支持 `--verify` 查状态、`--revert` 还原）。
